# Механизм наследования ресурсов (Shared Listener Inheritance)

Изолированный AB-тест: базовый Rust WSGI-сервер без включённых методов статьи сравнивается с тем же сервером, где включён только **Механизм наследования ресурсов (Shared Listener Inheritance)**. Обе конфигурации получают одинаковый POST-запрос и запускаются тем же тестовым приложением Django.

Запуск из корня репозитория:

```sh
benchmarks/01_shared_listener_inheritance/run.sh
```

Скрипт чередует порядок серверов, по умолчанию выполняет 2 прогревочных раунда на вариант и 10 пар измерений по 5 секунд, использует 4 потока wrk и 64 соединения. Выводит RPS, p95 и p99; сохраняет сырые раунды и сведения о среде в `results.json`.

Изменяемый параметр описан в `comparison.json`. Сводка теста не создаётся заранее: `results.json` появляется после реального запуска.
