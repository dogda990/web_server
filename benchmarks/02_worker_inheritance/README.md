# Механизм приёма унаследованных ресурсов (Worker Inheritance)

Изолированный AB-тест: базовый Rust WSGI-сервер без включённых методов статьи сравнивается с тем же сервером, где включён только **Механизм приёма унаследованных ресурсов (Worker Inheritance)**. Обе конфигурации получают одинаковый POST-запрос и запускаются тем же тестовым приложением Django.

Запуск из корня репозитория:

```sh
benchmarks/02_worker_inheritance/run.sh
```

Скрипт сначала измеряет RPS, p95 и p99 (2 прогревочных раунда на вариант, 10 пар измерений по 5 секунд, 4 потока wrk и 64 соединения). Затем выполняет по 40 холодных запусков каждого варианта, чередуя порядок. Время старта считается от `Popen` до первого HTTP 2xx от `/rps_plain`. Для старта в `results.json` записываются все пробы, медиана, среднее, стандартное отклонение, min/max и парные разности.

Изменяемый параметр описан в `comparison.json`. Сводка теста не создаётся заранее: `results.json` появляется после реального запуска.

## Результат 30.09.2026

Медиана старта составила 146,15 мс при прямом `bind` (SD 102,82; диапазон 116,91–792,89 мс) и 129,18 мс при приёме унаследованного FD (SD 4,80; 122,88–143,13 мс). Медиана парной разницы — −17,15 мс. Один baseline старт длился 792,89 мс и увеличил его разброс. Все 40 проб на вариант сохранены в `results.json`.
