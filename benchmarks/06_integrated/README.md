# Интеграция всех методов

Итоговое сравнение Rust WSGI-сервера со всеми пятью методами из статьи и Granian с лучшим исследованным в репозитории профилем.

Запуск из корня репозитория:

```sh
benchmarks/06_integrated/run.sh
```

По умолчанию сервер собирается в release-режиме; затем выполняются 2 прогревочных раунда на вариант и 10 измеряемых циклов по 5 секунд. Используются 4 потока wrk, 16 соединений и пауза 1 секунда. Число соединений снижено из-за 10-MiB тел; оно одинаково для двух серверов. Скрипт печатает RPS, p95 и p99 для обеих конфигураций и сохраняет сырые значения в `results.json`.

Нагрузка — ровно 70% быстрых `GET /rps_plain`, 20% тяжёлых `GET /rps_heavy` и 10% `POST /rps_heavy` с телом 10 MiB. Тяжёлый view задерживает ответ на 25 мс; большие тела полностью читаются, но ответы остаются короткими. Сценарий измеряет RPS, p95 и p99. Затем выполняются 40 чередуемых холодных стартов каждого сервера до первого HTTP 2xx от `/rps_plain`; статистика старта добавляется в тот же `results.json`. Точный профиль — в `comparison.json`, методика и версии — в [benchmark-methodology-ru.md](../../docs/benchmark-methodology-ru.md).
