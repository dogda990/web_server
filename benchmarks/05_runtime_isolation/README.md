# Изоляция сетевой среды выполнения (Runtime Isolation)

Изолированный AB-тест сравнивает inline-выполнение Django на потоке Tokio с передачей Python-вызова в blocking pool Tokio. wrk чередует 70% быстрых `GET /rps_plain` и 30% `GET /rps_heavy`; тяжёлый view делает `time.sleep(25 мс)` и отвечает коротким телом. Быстрый маршрут не менялся.

Запуск из корня репозитория:

```sh
benchmarks/05_runtime_isolation/run.sh
```

Скрипт чередует порядок серверов, выполняет 2 прогревочных раунда на вариант и 10 пар измерений по 5 секунд, использует 4 потока wrk и 64 соединения. Выводит RPS, p95 и p99; сохраняет сырые раунды и сведения о среде в `results.json`.

Изменяемый параметр описан в `comparison.json`. Сводка теста не создаётся заранее: `results.json` появляется после реального запуска.

Прогон 30.09.2026: inline baseline — 225,15 RPS, p95 437,588 мс, p99 489,923 мс; blocking pool — 7 294,63 RPS, p95 29,612 мс, p99 30,488 мс. Ошибок не было. Полные раунды и парный интервал находятся в `results.json`.
